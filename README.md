# hk4e-patch-universal

Genshin Impact encryption patch made mainly for [LunaGC_7.1.0](https://github.com/capyb2222/LunaGC_7.1.0). The patch should also work with other Grasscutter-based servers.

## Features
- Damage logger, toggled with `Ctrl+K`
- Menu, opened with `Ctrl+L`
- FPS unlocker (adjustable)
